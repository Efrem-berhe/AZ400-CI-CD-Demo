# \# AZ400 CI/CD Demo

# 

# \## Overview

# This repository is my practical learning project for Microsoft Azure DevOps and the AZ-400 certification.

# 

# \## Objectives

# \- Understand Git branching and pull requests.

# \- Build automated CI pipelines with GitHub Actions.

# \- Run automated tests and quality checks.

# \- Manage build artifacts and Docker containers.

# \- Practise deployment, security, and monitoring concepts.

# 

# \## Workflow

# 1\. Create a feature branch.

# 2\. Make and commit changes.

# 3\. Push the branch to GitHub.

# 4\. Open a pull request.

# 5\. Review the changes and validate the pipeline.

# 6\. Merge the changes into the main branch after successful checks.

# 

# \## Technologies

# \- Git and GitHub

# \- GitHub Actions

# \- PowerShell

# \- Docker

# \- Azure DevOps
